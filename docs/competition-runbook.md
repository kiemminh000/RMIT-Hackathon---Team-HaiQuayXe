# Competition runbook

This is our team process. The official brief and organiser instructions control the actual requirements.

## Before arrival

- Everyone can access the repository and Kaggle account; confirm the official team membership.
- Run bootstrap once with working internet. Re-run it if requirements change.
- One primary person and one backup can run the commands and upload required artifacts.
- Bring laptops, chargers, IDs, and required campus items; verify the latest local timetable.

## When the task is released

1. Fill in `2026-brief.md`: task, metric, permitted tools/data, exact outputs, submission limits, and deadlines/time zone.
2. Inspect real input files and the official sample. Resolve conflicting column names or instructions with the organisers.
3. Agree on the smallest valid solution and split work by independent responsibilities.
4. Reserve upload time and identify slow tasks such as model downloads or video processing.

## First working version

- Produce one valid end-to-end output early.
- Validate against the sample; manually check target meaning, row alignment, and required filenames.
- Save the working commit and output. Submit only after reading limits and requirements.
- Confirm the platform accepted it; a successful local export is not an accepted submission.

## Improve using evidence

Use a fixed local validation split and record results in an experiment note. Check leakage/duplicates and evaluate the relevant languages separately when applicable. Change one thing at a time. Keep the best working version intact and timebox experiments that stall.

## Final handoff

- Stop adding features with enough time left to rerun and upload.
- Have the backup teammate reproduce the chosen version from a clean process.
- Check the required files, schema, positive class, run time, and output directory.
- Recheck notebook names, repository visibility, reports, videos, and other brief-specific deliverables.
- Upload before the deadline and confirm acceptance or accessible links.
- Record the final commit, artifact location, and platform submission identifier.

The supplied Saigon South handbook lists 6 PM on 22 October 2026 as the submission deadline. Reconfirm the latest organiser notice on the day.
